# Screenshot provenance

These interface previews were generated from noato's native AppKit controllers and menu row views using `Tests/quillTests/DesignReviewTests.swift`. Meeting titles, queue states, progress and recent-history entries are fixtures, not user recordings. No audio was captured to create them.

The menu previews are rendered in a documentation window headed “Design review · Sample data”, rather than captured from a live menu bar popup. Settings images use the production settings controller. Rendering uses a native view bitmap fallback when macOS window capture is unavailable.

The documentation includes matching light/dark menu and progress previews, recording settings in light mode and transcription settings in dark mode. Personal home-directory paths, real meeting content and device identifiers are not included. Model and permission readiness shown here describe the fixture environment, not a guarantee about a new installation.

Regenerate with the command in the root README and inspect each selected image before replacing these files. Only include previews without personal paths or meeting content.
