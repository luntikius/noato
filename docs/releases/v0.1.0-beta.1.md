# noato v0.1.0-beta.1

The first noato beta brings local Zoom and Telemost recording and Markdown transcripts to the macOS menu bar.

## Install

Requires Apple Silicon, macOS 15+ and Apple developer tools with Swift 6.2.3+. Installation builds and ad-hoc signs the app locally; there is no notarized binary or DMG in this release. Models download during setup and then work offline.

Ask your coding agent:

```text
Read https://raw.githubusercontent.com/luntikius/noato/v0.1.0-beta.1/skills/install-noato/SKILL.md
and follow it to install and set up noato v0.1.0-beta.1 on this Mac.
```

See the [installation guide](../installation.md) for source installation and setup. Existing Quill users can import settings and pending work. Finish recording and transcription and quit the old app before installing.

## Included

- Separate microphone and meeting-app audio, with explicit input selection.
- Whisper large-v3-turbo, Russian by default, timestamps and anonymous remote speaker labels.
- Menu bar progress, queue, retry actions and five recent transcripts.
- Verified Markdown export followed by working-audio cleanup; failed work stays available for retry.
- Compact English settings, sequential permission/model setup, optional login and retention controls.

## Beta limitations

- Automatic detection uses audio activity and can start outside a meeting. Manual recording is recommended when this matters.
- Native Zoom and Telemost only; browser meetings and Intel Macs are not supported by this beta.
- macOS permission checks do not replace a real test meeting. Verify both tracks with a consenting participant before relying on recordings.
- Broader real-call and clean-macOS installation validation is still needed. Speaker separation and speech recognition can make mistakes.
- Optional retention deletes old queued/failed audio as well as transcripts. Active recording and processing are protected.
